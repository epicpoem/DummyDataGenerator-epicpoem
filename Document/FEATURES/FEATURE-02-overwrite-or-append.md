# FEATURE-02: 기존 데이터 처리 방식 선택

## 기능 목적

JSON 저장소에 기존 데이터가 존재하는 경우, 사용자가 데이터를 덮어쓸지(overwrite)
아니면 기존 데이터에 추가(append)할지 선택할 수 있도록 하여
의도치 않은 데이터 손실을 방지한다.

---

## 사용자 시나리오

1. 사용자가 더미 데이터 생성을 실행한다.
2. JSON 저장소에 기존 데이터가 존재하는 경우, 처리 방식 선택 프롬프트가 표시된다.
   - 선택지 예시:
     - [1] 덮어쓰기 (기존 데이터 삭제 후 생성)
     - [2] 추가 (기존 데이터 유지 후 더미 데이터 추가)
     - [0] 취소
3. 사용자가 선택하면 해당 방식으로 데이터를 저장한다.
4. 기존 데이터가 없으면 선택 없이 바로 저장한다.

---

## 입력

- 사용자 선택: 덮어쓰기 / 추가 / 취소

## 출력

- 덮어쓰기 선택 시: 기존 데이터 삭제 후 더미 데이터 저장, 완료 메시지 출력
- 추가 선택 시: 기존 데이터 유지하고 더미 데이터 추가 저장, 완료 메시지 출력
- 취소 선택 시: 데이터 변경 없이 종료 메시지 출력

## 예외 처리 기준

- 유효하지 않은 선택 입력 시: 재입력 안내 메시지 출력
- 추가 모드에서 중복 ID 시료가 존재하는 경우: 중복 항목은 건너뛰고 나머지만 추가, 건너뛴 항목 수 안내
