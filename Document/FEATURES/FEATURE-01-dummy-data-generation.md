# FEATURE-01: 더미 데이터 생성

## 기능 목적

SampleOrderSystem 테스트 및 개발 시 초기 데이터 세팅을 빠르게 수행하기 위해
미리 정의된 시료(Sample) 및 주문(Order) 더미 데이터를 생성하여 JSON 저장소에 저장한다.

---

## 사용자 시나리오

1. 사용자가 CLI에서 DummyDataGenerator를 실행한다.
2. 도구가 시작되면 메인 메뉴 또는 즉시 실행 옵션이 표시된다.
3. 사용자가 더미 데이터 생성을 선택(또는 실행)한다.
4. 사용자는 시드(seed) 값을 입력하거나 기본값(시드 없음)으로 진행할 수 있다.
5. 도구가 시드 기반으로 더미 데이터를 생성하여 JSON 파일에 저장한다.
6. 선택적으로 주문 데이터도 함께 생성할 수 있다.
7. 저장 완료 후 사용된 시드 값, 생성된 데이터 건수, 저장 경로를 화면에 출력한다.

---

## 생성 데이터 명세

### 시료 데이터 (필수, 5건)

| 필드            | 설명                         |
|----------------|------------------------------|
| id             | 시료 고유 식별자 (예: S-001)  |
| name           | 시료 명칭                     |
| productionTime | 1개당 평균 생산 시간 (min/ea) |
| yield          | 수율 (0.0 ~ 1.0)             |
| stock          | 현재 보유 재고 수량 (ea)      |

고정 더미 데이터:
- S-001, 실리콘 웨이퍼-8인치, 0.5, 0.92, 480
- S-002, GaN 에피택셀-4인치, 0.3, 0.78, 220
- S-003, SiC 파워기판-6인치, 0.8, 0.92, 30
- S-004, 포토레지스트-PR7, 0.2, 0.95, 910
- S-005, 산화막 웨이퍼-SiO2, 0.6, 0.88, 0

### 주문 데이터 (선택)

| 필드       | 설명                                            |
|------------|------------------------------------------------|
| orderId    | 주문 번호 (형식: ORD-{날짜}-{4자리 순번})        |
| sampleId   | 연결된 시료 ID                                  |
| customer   | 고객명                                          |
| quantity   | 주문 수량 (ea)                                  |
| status     | 주문 상태 (초기값: RESERVED)                    |

## 시드(Seed) 기능

### 목적
동일한 시드 값을 입력하면 항상 동일한 더미 데이터가 생성되어, 테스트 재현성을 보장한다.

### 요구사항
- 사용자는 데이터 생성 전 시드 값(정수)을 입력할 수 있어야 한다.
- 시드를 입력하지 않으면 기본 고정 데이터(스펙 예시 5건)가 생성된다.
- 동일한 시드 값을 입력하면 언제나 동일한 데이터가 생성되어야 한다.
- 서로 다른 시드 값은 서로 다른 데이터를 생성해야 한다.
- 생성 완료 후 화면에 사용된 시드 값이 표시되어야 한다.

### 시드 기반 가변 항목 (예시)
시드에 따라 달라질 수 있는 항목:
- 시료 재고 수량
- 주문 수량 (주문 데이터 생성 시)
- 주문 고객명 (주문 데이터 생성 시)

시드와 무관하게 고정되는 항목:
- 시료 ID (S-001 ~ S-005)
- 시료 명칭
- 평균 생산시간
- 수율
- 주문 상태 (항상 RESERVED)

---

## 입력

- 사용자 선택: 더미 데이터 생성 실행 여부
- 사용자 입력 (선택적): 시드 값 (정수, 미입력 시 기본 고정 데이터 사용)
- 사용자 선택 (선택적): 주문 데이터 포함 여부

## 출력

- 사용된 시드 값 출력 (기본값 사용 시 "기본 데이터" 표시)
- 생성된 시료 수, 주문 수 출력
- JSON 파일 저장 경로 출력
- 성공/실패 메시지

## 예외 처리 기준

- 시드 입력값이 정수가 아닌 경우: 재입력 안내 메시지 출력
- JSON 파일 저장 실패 시: 오류 메시지 출력 후 프로그램 정상 종료
- 대상 디렉토리가 없는 경우: 자동 생성 후 저장 시도
