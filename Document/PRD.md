# PRD - DummyDataGenerator (Dummy 데이터 생성 Tool)

## 제품 개요

DummyDataGenerator는 SampleOrderSystem 개발 및 테스트 시 초기 데이터를 빠르게 세팅하기 위한 CLI 도구다.
사용자는 이 도구를 실행하여 미리 정의된 시료(Sample) 및 주문(Order) 더미 데이터를 JSON 저장소에 저장할 수 있다.

---

## 사용자 요구사항

### 1. 더미 데이터 생성

- 사용자는 도구를 실행하여 미리 정의된 시료(Sample) 더미 데이터를 생성할 수 있어야 한다.
- 사용자는 더미 데이터 생성 시 최소 5건의 시료 데이터가 생성됨을 확인할 수 있어야 한다.
- 사용자는 선택적으로 RESERVED 상태의 주문(Order) 더미 데이터도 함께 생성할 수 있어야 한다.

### 2. 기존 데이터 처리 선택

- 사용자는 더미 데이터 생성 전, 기존 JSON 저장소에 데이터가 존재할 경우 덮어쓰기(overwrite) 또는 추가(append) 방식 중 선택할 수 있어야 한다.
- 사용자는 의도치 않은 데이터 덮어쓰기를 방지하기 위해 확인 단계를 거쳐야 한다.

### 3. 저장 결과 확인

- 사용자는 생성 완료 후 저장된 데이터 건수(시료, 주문)를 화면에서 확인할 수 있어야 한다.
- 사용자는 JSON 파일이 저장된 경로를 화면에서 확인할 수 있어야 한다.

### 4. SampleOrderSystem 호환성

- 생성된 더미 데이터는 SampleOrderSystem이 사용하는 JSON 스키마와 동일한 포맷으로 저장되어야 한다.
- 사용자는 DummyDataGenerator로 생성한 JSON 파일을 SampleOrderSystem에서 별도 변환 없이 바로 사용할 수 있어야 한다.

## 생성할 더미 데이터 명세

### 시료 (Sample) - 최소 5건

| ID    | 이름                  | 평균 생산시간 | 수율 | 재고  |
|-------|-----------------------|--------------|------|-------|
| S-001 | 실리콘 웨이퍼-8인치   | 0.5 min/ea   | 0.92 | 480   |
| S-002 | GaN 에피택셀-4인치    | 0.3 min/ea   | 0.78 | 220   |
| S-003 | SiC 파워기판-6인치    | 0.8 min/ea   | 0.92 | 30    |
| S-004 | 포토레지스트-PR7      | 0.2 min/ea   | 0.95 | 910   |
| S-005 | 산화막 웨이퍼-SiO2   | 0.6 min/ea   | 0.88 | 0     |

### 주문 (Order) - 선택 사항

- RESERVED 상태의 주문 수 건 생성 가능
- 위 시료 데이터를 참조하는 주문으로 구성

---

## 비기능 요구사항

- 사용자는 CLI(명령줄) 환경에서 도구를 실행할 수 있어야 한다.
- 사용자는 잘못된 입력을 하더라도 프로그램이 비정상 종료되지 않고 적절한 안내 메시지를 받을 수 있어야 한다.
- 사용자는 도구 실행 후 정상 종료 여부를 종료 메시지로 확인할 수 있어야 한다.
